GLAM BY JODY WEBSITE
===========================

Open index.html in a web browser to start the website.

Pages:
Home, Products, Services, Gallery, Reviews, Sales, Orders, Checkout, About, Contact.

Features:
- Shared navigation across all pages
- Responsive CSS
- Product add-to-cart using localStorage
- Cart count in navigation
- Remove items and clear cart
- Checkout form
- Demo order history saved in localStorage
- Booking buttons
- Gallery, reviews and sales pages

Note:
The gallery/product images use Unsplash URLs, so an internet connection is needed for those images to display.
