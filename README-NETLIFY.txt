NETLIFY DEPLOYMENT
1. Upload the Lumiere-Beauty folder or connect the GitHub repository.
2. Publish directory: .
3. No build command is required.
4. After deployment, submit contact.html and enquiry.html once so Netlify Forms detects submissions.
5. In Netlify > Forms > Form notifications, add the email notification required by your lecturer/project.
6. Test all links and the map on the deployed HTTPS URL.
